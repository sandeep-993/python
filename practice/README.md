# Practice Code and Interview Exercises

Use this directory for runnable examples and your own solutions. Keep explanations in `notes/` and use descriptive filenames such as `04_strings.py` or `06_functions.py`.

## Suggested workflow

1. Read a topic note and attempt its exercises without copying a solution.
2. Put each solution in a small function with clear inputs and outputs.
3. Add a few test cases, including empty input, a typical case, boundaries, and duplicates where relevant.
4. Run the file with `python practice/filename.py` (or `python3`, depending on your setup).
5. Write down the time and additional-space complexity and explain your approach aloud.

Example layout:

```text
practice/
├── 01_basics.py
├── 04_strings.py
├── 05_data_structures.py
└── 06_functions.py
```

Do not commit passwords, API keys, or other secrets. Avoid putting a practice solution in a file named after a standard-library module such as `random.py` or `json.py`, since that can shadow the real module.
