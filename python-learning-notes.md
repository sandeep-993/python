# Python Learning Notes

## Topic 1: Python Basics

- Python is a high-level, interpreted language.
- It uses indentation instead of braces for blocks.
- Variables store values without explicit type declarations.

## Topic 2: Data Types

- `int` for integers
- `float` for decimals
- `str` for text
- `bool` for True/False
- `list`, `tuple`, `dict`, `set` for collections

## Topic 3: Control Flow

- `if`, `elif`, `else` for conditions
- `for` and `while` for loops
- `break` and `continue` for loop control

## Topic 4: Functions

- Functions help reuse code.
- A function can accept parameters and return a value.

```python

def add(a, b):
    return a + b

print(add(2, 3))
```
