## How to use these notes

For each topic:

1. Read the concept and examples.
2. Close the notes and explain the key idea in your own words.
3. Type and run the examples; modify them to test your understanding.
4. Solve the exercises in `practice/` or write your own solutions.
5. Test normal, boundary, empty, and invalid inputs where applicable.
6. Explain the solution, time complexity, and extra space as you would in an interview.

## Interview problem-solving routine

- Clarify input constraints, expected output, and edge cases.
- Give a simple approach first, then improve it if needed.
- Choose data structures based on the operations the solution needs.
- Write readable code with descriptive names.
- Dry-run the code on a small example.
- State time and auxiliary-space complexity accurately.

These notes support learning and practice; interview requirements vary by role, so use the job description to decide which areas to prioritize.
