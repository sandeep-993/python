A topic-by-topic guide for learning Core Python. Each topic has notes and examples; use the practice directory for runnable exercises.

## Suggested study loop

For each topic, read the notes, type and modify the examples, then solve the exercises without looking at the solution. Put experiments in `practice/` and record questions or useful discoveries in the relevant note.
