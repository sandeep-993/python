## How to prepare for interviews

- Learn one concept at a time.
- Read the examples and then write your own.
- Explain the logic out loud as if in an interview.
- Practice at least 3 coding problems per topic.
- Write code without looking at the notes.

## Study habit

For every topic, do this:

1. Understand the concept.
2. Learn the syntax.
3. Solve 2-3 coding questions.
4. Discuss time/space complexity.
5. Re-explain the solution clearly.
